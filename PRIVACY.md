# Privacy policy: Kernel Kids Uploader

Kernel Kids Uploader is a private tool that the owner of the Kernel Kids YouTube channel uses to upload
and schedule that channel's own videos and to read the channel's own analytics.

- It is used only by the channel owner, with the owner's own Google account. It has no other users.
- It accesses YouTube data (video uploads, video status and channel analytics) only through the
  YouTube Data API and YouTube Analytics API, and only for that channel.
- OAuth tokens are stored only on the owner's computer and as encrypted GitHub Actions secrets in this repository.
- No data is sold, shared with third parties, or used for advertising.
- To revoke access, go to https://myaccount.google.com/permissions.

Contact: open an issue at https://github.com/aliasgharab/yt-auto/issues
